# 千问办公

千问办公的具体 Skill 导入入口可能随客户端版本和账号类型变化。本仓库不伪造一个未经验证的专用命令。

推荐顺序：

1. 在千问办公中找到自定义技能、工作流或 Agent 配置入口。
2. 先导入单个 Skill 的 `SKILL.md`，不要一次性粘贴整个仓库。
3. 同时提供该 Skill 所需的 `references/`、`assets/` 和示例文件。
4. 对需要本地执行的脚本，先确认千问办公是否支持本地文件访问、命令执行或外部 MCP。
5. 用固定样例验证输出，再决定是否导入下一套 Skill。

只要千问办公支持标准 Markdown Skill 或等价的 Agent 工作流描述，就可以使用本仓库的第一方 Skill 内容；平台的工具权限和文件处理能力仍需单独核对。
