# Trae and WorkBuddy

These clients may use platform-specific Skill or Agent import conventions.
The portable unit is each directory containing a `SKILL.md`; import the
first-party Skill directories individually and resolve their documented tool
dependencies locally.

Do not assume that a Claude Code plugin manifest or a Codex discovery path is
accepted unchanged by Trae or WorkBuddy. Keep platform-specific launchers and
configuration outside the Skill content.
