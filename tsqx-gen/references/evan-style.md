# Evan Style Notes

These notes summarize the preserved TSQX examples found in Evan Chen handouts and the surrounding Asymptote code style.

## Main Style Signal

Prefer pure TSQX whenever the construction is already expressible by built-ins.

In the preserved examples, the code stays compact:

- free points by `dir`
- derived points by `incenter`, `foot`, `midpoint`, `extension`
- drawing by direct path lines and circle helpers

There is no unnecessary fallback to raw Asymptote.

## Typical Shape

The extracted handout examples follow this pattern:

1. declare anchor points
2. declare standard derived points
3. draw the main figure
4. draw one or two highlighted relations

Example ingredients:

- `I 315 = incenter A B C`
- `D = foot I B C`
- `M = midpoint B--C`
- `K = extension M N E F`
- `incircle A B C / blue`

## Implication For This Skill

- Do not use `!pair` or `!path` when a standard TSQX built-in already matches the geometry.
- Treat raw Asymptote as an escape hatch, not a default.
- Favor short, declarative construction lines over coordinate-heavy algebra unless exact metric control is essential.

## Limits Of The Preserved Dataset

Only a small number of handout figures still contain the original TSQX comments verbatim.
Some older figures contain only the placeholder comment `Source generated by TSQ`.

Therefore:

- use the extracted TSQX snippets as high-quality style anchors
- use the surrounding Asymptote figures as secondary evidence about construction preferences
- do not claim that every Evan handout figure has recoverable original TSQX
